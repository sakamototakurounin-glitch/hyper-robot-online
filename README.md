# ハイパーロボット ONLINE

ルーム名だけで集まれる、1人から何人でも遊べるオンライン対戦ロボットパズルです。

## 遊び方

1. プレイヤー名を決めます。
2. ルームを作成するか、同じルーム名を入力して参加します。
3. ルーム作成者がゲームを開始します。
4. 頭の中でルートを考え、「解答する」を押してから盤面のコマと方向を順にクリック／タップします。
5. 最初の正解登録から60秒後、最少手数を最も早く登録したプレイヤーが1点を獲得します。

問題は毎ラウンド生成され、幅優先探索で最短手数を計算します。最短が5手未満の問題は採用されません。登録された手順はサーバーで再実行して検証します。

## 構成

- Cloudflare Workers互換のES Modules Worker
- D1（ルーム、プレイヤー、ラウンド、得点、実況イベント）
- Vanilla JavaScript / SVG
- ポーリングによるルーム同期

Sites向けの論理バインディングは `.openai/hosting.json` の `DB` です。スキーマ変更は `db/schema.ts`、初期マイグレーションは `drizzle/0000_multiplayer.sql` にあります。
