# ハイパーロボット ONLINE

ルーム名だけで集まれる、1人から何人でも遊べるオンライン対戦ロボットパズルです。

## 遊び方

1. プレイヤー名を決め、ルームを作成または同名ルームへ参加します。
2. ルーム作成者がゲームを開始します。
3. 同期カウントダウン後に目的地が現れたら、最短ルートを探します。
4. 「解答する」を押し、ロボットと方向をクリック／タップして実際の手順を入力します。
5. 受付終了時に、自己最短手数が少なく、同手数なら探索時間が短いプレイヤーがラウンドを獲得します。

問題は毎ラウンド生成され、幅優先探索で理論上の最短手数を計算します。最短が5手未満の問題は採用しません。登録手順はサーバーで再実行して検証します。

## ルーム設定

- 初登録後の受付時間: 45 / 60 / 75 / 90 / 105 / 120秒
- 理論値最短ボーナス: ON / OFF
- 総ラウンド数: 3 / 5 / 7 / 10 / 15 / 20
- 1ラウンド最大時間: 3〜10分

実際の終了時刻は、最大時間と初登録後タイマーの早い方です。

## 同期と保存

- サーバー共通の未来時刻を使った「3 → 2 → 1」カウントダウン
- サーバー終了時刻から毎回算出する残り時間
- 各プレイヤーの初登録、自己最短、暫定首位、理論値達成をD1へ保存
- ラウンド終了時に一度だけ、solo / duel / multiplayer 別の能力データを更新
- Liveは解答中と暫定1位を常時表示し、その他の通知と自己最短は10秒で整理

## 構成

- Cloudflare Workers互換のES Modules Worker
- D1（ルーム、プレイヤー、ラウンド、個人ベスト、能力データ、実況イベント）
- Vanilla JavaScript / SVG
- ポーリングとサーバー時刻補正によるルーム同期

Sites向けの論理バインディングは「DB」です。初期スキーマは「drizzle/0000_multiplayer.sql」、追加仕様の移行は「drizzle/0001_round_state_stats.sql」にあります。
